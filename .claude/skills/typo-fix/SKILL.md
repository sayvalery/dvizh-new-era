# 🔤 Typo-fix — Типографика для русских .astro

Скилл проверяет и расставляет:
- `ё` → `е` (везде)
- Неразрывный пробел (` `) после коротких предлогов (в, на, по, с, до, для, не и т.д.)
- NBSP между числом и кириллицей («5 минут» → «5 минут»)
- NBSP в разрядах числа («1 700» → «1 700»)
- NBSP между числом и `% ₽ € $`
- NBSP перед `—`

Идемпотентен: повторный запуск ничего не меняет.

## Когда вызывать

- **Перед публикацией в dev** — скилл `sync` сам предложит прогнать `typo-fix` (Режим 2, шаг 1.5).
- **Вручную в любой момент** — когда нужно убедиться, что контент в порядке.
- **Перед фиксом дизайна / финальным просмотром** — чтобы не отправлять PR с ё.

## Скоуп

Дефолт — **только файлы, изменённые в текущей ветке** относительно `origin/dev` + unstaged изменения. Это безопасно: не загрязняет diff чужими страницами, не плодит merge-конфликты.

Аргумент `all` — все `.astro` в `apps/web/src/pages/**/*.astro` + `apps/web/src/components/**/*.astro`. Используй для генеральной уборки.

## Процесс

### Шаг 1: Определить скоуп

Если пользователь вызвал с аргументом `all` или `--all`:
```bash
files="--all"
```

Иначе:
```bash
git fetch origin dev --quiet
# Файлы из текущей ветки относительно origin/dev (только .astro в pages + components):
changed=$(git diff --name-only origin/dev...HEAD -- 'apps/web/src/pages/*.astro' 'apps/web/src/components/**/*.astro' 2>/dev/null)
# Плюс unstaged/staged:
unstaged=$(git status --porcelain -- 'apps/web/src/pages/*.astro' 'apps/web/src/components/**/*.astro' | awk '{print $NF}')
files=$(printf '%s\n%s\n' "$changed" "$unstaged" | sort -u | grep -v '^$')
```

Если `files` пустой и не указан `all` — вывести:
```
🔤 ═══════════════════════════════════════
   TYPO-FIX · ПРОВЕРКА ТИПОГРАФИКИ
═══════════════════════════════════════
   Нет изменённых .astro файлов в pages/ или components/.
   Используй `/typo-fix all` для прогона по всему проекту.
═══════════════════════════════════════
```
и завершиться.

### Шаг 2: Dry-run

```bash
python3 scripts/typo-fix.py --dry-run --diff $files
```

(или `--all` вместо списка)

Скрипт сам выведет per-file stats и unified diff. Exit code 0 — изменений нет, exit 1 — есть.

### Шаг 3: Если exit 0 — завершиться

```
🔤 ═══════════════════════════════════════
   TYPO-FIX · ПРОВЕРКА ТИПОГРАФИКИ
═══════════════════════════════════════
👤 Скоуп ........................ <N> файлов
✓ Типографика уже в порядке
═══════════════════════════════════════
```

### Шаг 4: Если exit 1 — показать diff и спросить пользователя

Diff уже выведен скриптом. Спроси:
- **Применить правки?** (да / нет)

### Шаг 5: На «да» — `--write`

```bash
python3 scripts/typo-fix.py --write $files
```

Файлы перезаписаны. Изменения остаются в рабочем дереве (НЕ коммитятся).

Вывод:
```
🔤 ═══════════════════════════════════════
   TYPO-FIX · ПРАВКИ ПРИМЕНЕНЫ
═══════════════════════════════════════
📂 Файлов ....................... <N>
📝 NBSP ........................ <K>
🔡 ё → е ....................... <M>
═══════════════════════════════════════
   Изменения в рабочем дереве.
   Закоммить их перед мержем в dev:
     git add <files>
     git commit -m "typo: NBSP + ё→е"
═══════════════════════════════════════
```

### Шаг 6: На «нет» — выйти без изменений

## Важно

- **Только контент.** Правила применяются исключительно к HTML-текстовым узлам. Frontmatter (`--- ... ---`), теги с атрибутами (включая `class` и выражения `{...}`), `<script>`/`<style>` и комментарии не трогаются — NBSP в коде ломает разбивку Tailwind-классов. Текст внутри `{...}`-выражений (напр. `{cond ? 'в офисе' : 'дома'}`) тоже считается кодом и не обрабатывается.
- Сам коммит не делает — это работа пользователя или скилла `sync`.
- Не трогает `apps/cms/` и другие папки — только `apps/web/src/pages/` и `apps/web/src/components/`.
- Если файл удалён или нечитаем — пропускает с предупреждением, не падает.
- Скрипт `scripts/typo-fix.py` — единственный источник правды для правил. Не дублируй логику в самом скилле.
