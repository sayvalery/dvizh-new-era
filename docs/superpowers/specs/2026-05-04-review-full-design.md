# ReviewFull — компонент отзыва с фото спикера

**Дата:** 2026-05-04  
**Статус:** утверждён  
**Автор:** Valery (v.syzranov@dvizh.io)

---

## Задача

Создать новый UI-компонент `ReviewFull.astro` — расширенный блок отзыва с фотографией спикера слева. Существующий `Review.astro` не изменяется; `ReviewFull` использует его как внутренний компонент.

---

## Дизайн

### Макет (десктоп)

```
┌─────────────────────────────────────────────────────────┐
│  [фото]       │  "Цитата спикера..."                    │
│               │                                         │
│  object-cover │  [logo] │ Имя Фамилия   [Читать кейс]  │
│  h-full       │         │ Должность                    │
└─────────────────────────────────────────────────────────┘
```

### Макет (мобайл)

Колонки складываются вертикально: фото сверху с `aspect-[4/3]`, контент снизу.

---

## Компонент

**Файл:** `apps/web/src/components/ui/ReviewFull.astro`

### Props

| Prop | Тип | Обязательный | Описание |
|------|-----|:---:|---------|
| `photo` | `{ src: string; alt?: string }` | ✓ | Фото спикера |
| `quote` | `string` | ✓ | Текст цитаты |
| `author` | `string` | ✓ | Имя автора |
| `role` | `string` | ✓ | Должность / роль |
| `company` | `{ logo: string; alt?: string }` | — | Логотип компании |
| `caseLink` | `{ label?: string; href: string }` | — | Ссылка на кейс |
| `class` | `string` | — | Дополнительные CSS-классы |

### Реализация

- Внешний контейнер: `flex rounded-2xl overflow-hidden bg-gray-100` (скругление обрезает фото)
- **Левая колонка** (`w-72` / ~280px, фиксированная): `relative` контейнер, фото `absolute inset-0 object-cover w-full h-full`; на мобайле — `aspect-[4/3] w-full relative` (высота авто)
- **Правая колонка** (`flex-1`): паддинги `p-8 lg:p-10`, внутри — `<Review {...reviewProps} />`
- Заглушка вместо фото: серый блок `bg-gray-200` (для случаев без реального src)

### Адаптивность

- `flex-col lg:flex-row` на внешнем контейнере
- Фото: мобайл `aspect-[4/3]` → десктоп `self-stretch` (полная высота)
